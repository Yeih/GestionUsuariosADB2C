# Proyecto

    Administrador de usuarios en directorio activo azure B2C

# Iniciar el servidor

Existen dos formas, desde la consola de comandos podemos escribir cualquiera de los siguientes comandos:

    1. >npm star
    2. >node server.js

# Modulos

Para este proyecto instalamos varios modulos entre ellos:

    1. >npm init -y
    2. >npm install express
    3. >npm install cors
